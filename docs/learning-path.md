# 学习路线与记录模板

## 推荐顺序

1. TCP 并发：分别改变总连接数与并发上限，观察连接建立和 echo RTT。
2. 线程池竞争：用不同的 UV_THREADPOOL_SIZE 启动独立 Node 进程，比较 fs 与 PBKDF2。
3. CPU 阻塞：比较同步计算和 Worker Threads，观察定时器延迟。
4. Event Loop 监控：观察 delay histogram 与 ELU 在空闲、阻塞、异步负载下的变化。
